# Training — Fuel Officer

## Input Fuel Harian

1. Buka daily entry untuk tanggal hari ini
2. Tab **Fuel**:
   - Tambah baris per equipment
   - Isi: unit, shift, liter, jam kerja, kategori usage
   - Gunakan Equipment Picker (search by unit code)
3. Simpan tab → Submit entry

## Fuel Dashboard

1. **Dashboard → Fuel** — konsumsi per equipment, FCR trend
2. Monitor anomali FCR (notifikasi otomatis jika outlier)
