# Training — Supervisor

## Tugas Harian

1. Login ke ARKA MineOps (`admin@mineops.test` untuk demo)
2. Pilih site aktif di header
3. **Data Entry → Daily Entries → Buat Baru**
4. Pilih tanggal + site → isi 4 tab:
   - **Produksi**: OB/Coal per PIT per shift
   - **Fuel**: konsumsi BBM per alat
   - **Equipment**: deployment per shift
   - **Info Site**: cuaca, hujan, manpower
5. **Submit** setelah lengkap
6. Tunggu approval dari supervisor lain

## Offline (PWA)

- Install app via "Add to Home Screen"
- Data tersimpan lokal saat offline
- Auto-sync saat online (tombol Sync manual tersedia)
