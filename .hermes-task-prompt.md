# Bug Fix: Mobile sidebar menu — Master Data submenu not discoverable

## Problem
User Iwan can't find PITs because it's hidden inside collapsed "Master Data" submenu in the sidebar/drawer. On mobile drawer, nested menus are hard to discover.

## Fix
Flatten the sidebar menu — remove the "Master Data" and "Plan" parent nesting. Make ALL items direct top-level menu items so nothing is hidden behind a collapse.
