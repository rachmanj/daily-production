# Bug Fix: Daily Entry Create Page Error

## Symptom
Opening `/daily-entries/create` redirects to `https://localhost:8080/login` instead of proper auth redirect. APP_URL likely wrong on VPS.

## Steps
1. Read the VPS .env file at `~daily-production/.env`
2. Check APP_URL is set correctly
3. The FORCE_HTTPS + APP_URL must match the funnel URL
4. Fix and verify

## Context
- VPS: vpsiwan1@100.77.117.2
- App runs via systemd: `daily-production.service`
- Access URL: https://vps-iwan1.tail8334ce.ts.net
- Port: 8080

## Fix
SSH into VPS and:
1. Check current .env APP_URL
2. Fix APP_URL to match the actual URL
3. Clear config cache
4. Restart service

Also check if there are any PHP errors in the Laravel log for the /daily-entries/create route.

Run these SSH commands:
```bash
cd ~/daily-production
grep APP_URL .env
grep FORCE_HTTPS .env
tail -20 storage/logs/laravel.log
```

Then fix .env:
```bash
sed -i 's|APP_URL=.*|APP_URL=https://vps-iwan1.tail8334ce.ts.net|' .env
sed -i 's|FORCE_HTTPS=.*|FORCE_HTTPS=false|' .env  
# FORCE_HTTPS should be false since Tailscale Funnel handles HTTPS -> HTTP proxy
php artisan config:clear
sudo systemctl restart daily-production
```

Verify:
```bash
curl -s http://localhost:8080/daily-entries/create -H 'Accept: text/html' | head -5
# Should show HTML page, not redirect to wrong URL
```
